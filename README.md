# teamglow
Client-side Minecraft Fabric mod that highlights teammates through walls with customizable glow colors, scoreboard team support, teammate management, and HUD features.
# 📖 How to Use TeamGlow

## 1. Opening TeamGlow Settings

You can open the configuration screen in two ways:

- Press `K` after assigning it in Minecraft Controls.
- Type `/tg` in chat.

**To assign K:**
1. Open Minecraft Options.
2. Select Controls.
3. Find the Teammate Glow category.
4. Find Open Teammate Glow Settings.
5. Assign the key `K`.

## 2. Adding Teammates

There are two ways to add teammates.

**Method 1: Using the Crosshair**
1. Look directly at a player.
2. Press `G`.
3. The player will be added to your teammate list.

Press `G` again while looking at an added teammate to remove them.

**Method 2: Using Settings**
1. Open TeamGlow settings.
2. Go to the Teammates tab.
3. Enter the player's username.
4. Click Add.

## 3. Enabling Teammate Glow

Press `J` to turn teammate glow ON or OFF.

You can also use:

- `/tg on` – Enable glow.
- `/tg off` – Disable glow.
- `/tg toggle` – Toggle glow.

## 4. Customizing Glow Colors

1. Open TeamGlow settings.
2. Find the Colour section.
3. Enter a six-digit HEX color code.
4. Preview your selected color.

Example colors:

- Cyan: `00E5FF`
- Green: `00FF00`
- Red: `FF0000`
- Purple: `AA00FF`
- Yellow: `FFFF00`

You can also use:

`/tg color 00E5FF`

## 5. Managing Glow Distance

You can customize how far away teammates can be highlighted.

Examples:

- `/tg distance 64` – 64 blocks.
- `/tg distance 128` – 128 blocks.
- `/tg distance 0` – Unlimited distance.

## 6. Scoreboard Team Support

Enable scoreboard team highlighting to automatically highlight players who share your Minecraft scoreboard team.

- `/tg teams on` – Enable.
- `/tg teams off` – Disable.

## 7. Invisible Teammates

You can choose whether invisible teammates should also be highlighted.

- `/tg invisible on` – Enable.
- `/tg invisible off` – Disable.

## 8. HUD Settings

TeamGlow includes an optional HUD badge that displays the number of teammates in range.

You can:
- Enable or disable the HUD badge.
- Choose its screen corner.
- Enable or disable the crosshair add hint.

Available badge positions:
- Top Left
- Top Right
- Bottom Left
- Bottom Right

## 9. Teammate Management Commands

| Command | Description |
|---|---|
| `/tg list` | View your teammate list |
| `/tg add <player>` | Add a teammate |
| `/tg remove <player>` | Remove a teammate |
| `/tg reload` | Reload configuration |
| `/tg status` | View current settings |
| `/tg help` | Show available commands |

## 10. Important Notes

- TeamGlow is a client-side Fabric mod.
- Your settings are saved locally.
- Check multiplayer server rules before using visual-assist features.
